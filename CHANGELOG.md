## [0.1.0] - 2026-05-27

### Added
- Initial release of TablePID
- Multi-database support: PostgreSQL, MySQL, MariaDB, SQLite
- AI SQL Assistant with multiple providers:
  - Ollama (local)
  - OpenAI
  - Anthropic
  - Google Gemini
- Context-aware AI that understands your database schema
- Query Editor powered by Monaco Editor
- Autocomplete for tables, columns, and functions
- ERD Generator with export to PNG
- Schema Compare tool
- SSH Tunnel support
- 10 beautiful themes:
  - Dark, Light, Ocean, Forest, Sunset
  - Purple, Sakura, Candy, Unicorn, Lavender
- 20+ keyboard shortcuts
- Session restore
- Auto reconnect
- Connection encryption (OS keychain)
- Inline data editing
- Import/Export SQL and CSV
- Query history
- Parameterized queries

### Security
- Credentials stored in OS keychain
- SSH tunnel for secure remote connections
